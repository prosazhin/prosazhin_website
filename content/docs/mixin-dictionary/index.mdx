`mixin-dictionary` собирает из дизайн-токенов CSS-переменные, переменные LESS и SCSS и миксины: текстовые стили, медиазапросы и keyframes. Пакет работает на основе [Style Dictionary](https://styledictionary.com) и используется при сборке [pbstyles](/docs/pbstyles).

Ресурсы: [npm](https://www.npmjs.com/package/mixin-dictionary) · [GitHub](https://github.com/prosazhin/mixin-dictionary) · [Changelog](https://github.com/prosazhin/mixin-dictionary/blob/main/CHANGELOG.md) · [Плейграунд](/docs/mixin-dictionary/playground).

## Почему этот пакет

- **JSON-конфиг без кода.** Один `config.json`, без JS/TS-скрипта сборки.
- **DTCG и старый формат.** Пакет читает [W3C Design Tokens (DTCG 2025.10)](https://www.designtokens.org/tr/2025.10/format/) (`$value`, `$type`, составные `typography` и `shadow`) из [Figma](/docs/mixin-dictionary/figma), Tokens Studio и Terrazzo, и старый формат Style Dictionary (`value`) с одинаковым результатом.
- **Темы на любом уровне DOM.** Светлая, тёмная и другие темы переключаются атрибутом `data-theme` на `<html>` или на вложенном контейнере. Переменные LESS и SCSS семантических токенов ссылаются на CSS-переменные, поэтому тема меняется без пересборки.

## Быстрый старт

```bash
npm install --save-dev mixin-dictionary
```

```json
{
  "$schema": "./node_modules/mixin-dictionary/schema/config.schema.json",
  "platforms": ["css", "less", "scss"],
  "source": ["tokens/*.json"],
  "output": "./styles"
}
```

```bash
npx mixin-dictionary
```

Результат появится в `styles/css/index.css`, `styles/less/index.less` и `styles/scss/index.scss`:

```scss
@import './styles/scss/index.scss';

.title {
  @include h64;
}

@include lg {
  .sidebar {
    display: none;
  }
}
```

## Что нового в 1.6

- Вход в формате DTCG 2025.10 и составные токены `typography` и `shadow`.
- Миксины текстовых стилей, брейкпоинтов и анимаций собираются без поля `mixin`.
- Любое число тем и `themes.default`.
- Программный API, TypeScript-типы, JSON Schema конфига и `--watch`.
- Понятные ошибки в одну строку с путём токена и именем файла.

Конфиги и токены версии 1.4 работают без изменений. Результат отличается только для путей токенов в camelCase или с `_`: раньше переменная и миксин получали разные имена, теперь имена совпадают. Полный список изменений и исправлений — в [CHANGELOG](https://github.com/prosazhin/mixin-dictionary/blob/main/CHANGELOG.md).
