`@prosazhin/pbstyles` is a set of basic styles for building interfaces quickly. It includes typography, a palette, semantic colors, sizes, containers, breakpoints, border radii, opacity and shadows. The same tokens ship as CSS, LESS, SCSS and a Tailwind CSS 4 theme.

Resources: [GitHub](https://github.com/prosazhin/pbstyles) · [npm](https://www.npmjs.com/package/@prosazhin/pbstyles) · [Figma Community](https://www.figma.com/community/file/1213609862805339771) · [Behance](https://www.behance.net/gallery/162935391/pbstyles) · [Design system](/design-system).

## Installation

```bash
npm install @prosazhin/pbstyles
```

The package contains ready-made files. You don't need to run the generators to use the published styles.

## Tailwind CSS 4

```css
@import 'tailwindcss';
@import '@prosazhin/pbstyles/styles/tailwind/theme.css';
```

After the import, token-based utilities are available: colors `bg-basic-0`, `text-basic-400`, `text-primary-400`, text styles `text-h64`, `text-t16`, as well as sizes, radii and shadows from the theme. This site uses the package exactly this way. The import also works with a Tailwind prefix, for example `@import 'tailwindcss' prefix(tw);`.

## CSS, LESS and SCSS

```css
@import '@prosazhin/pbstyles/styles/css';
```

```less
@import '@prosazhin/pbstyles/styles/less';
```

```scss
@import '@prosazhin/pbstyles/styles/scss';
```

LESS and SCSS include mixins for text styles, breakpoints and animations:

```scss
.title {
  @include h64;
}

@include mobile {
  .sidebar {
    display: none;
  }
}
```

## Formats

| Format     | Import                                          | Contents                                            |
| ---------- | ----------------------------------------------- | --------------------------------------------------- |
| CSS        | `@prosazhin/pbstyles/styles/css`                | CSS variables and the semantic theme.               |
| LESS       | `@prosazhin/pbstyles/styles/less`               | Variables and mixins.                               |
| SCSS       | `@prosazhin/pbstyles/styles/scss`               | Variables and mixins.                               |
| Tailwind 4 | `@prosazhin/pbstyles/styles/tailwind/theme.css` | Theme, token-based utilities and light/dark values. |

## What's included

| Category                                                                             | CSS | LESS | SCSS | Tailwind 4 |
| ------------------------------------------------------------------------------------ | --- | ---- | ---- | ---------- |
| Typography, colors, sizes, containers, breakpoints, borders, radii, opacity, shadows | ✓   | ✓    | ✓    | ✓          |
| Columns                                                                              | ✓   | ✓    | ✓    | —          |
| Animation, typography and breakpoint mixins                                          | —   | ✓    | ✓    | ✓          |

Plain CSS has variables without mixins. LESS and SCSS have variables and mixins; in Tailwind 4 they become part of the theme and utilities.

## Version 1.4

Since 1.4 the pbstyles source tokens use the [DTCG 2025.10](https://www.designtokens.org/tr/2025.10/format/) standard. **The generated styles did not change**: upgrading from 1.3 requires no changes in your project. See [DTCG tokens](/docs/pbstyles/tokens) for details.

## How the package is built

The CSS/LESS/SCSS files are generated by [mixin-dictionary](/docs/mixin-dictionary), and the Tailwind CSS theme by [tailwind-dictionary](/docs/tailwind-dictionary), from the tokens of the `pbstyles` repository. CI checks that the published styles match the token build.
