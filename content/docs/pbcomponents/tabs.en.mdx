Pass `Tab` elements as children. `theme` sets the appearance: `line` (default), `pill`, or `pill-secondary`. `index` enables controlled mode, `defaultIndex` sets the initial tab. `onChange` receives the index and the event; it also fires on keyboard navigation with arrows, `Home`, and `End`. The markup uses the `tablist`, `tab`, and `tabpanel` roles.

## Usage

```tsx
import { Tab, Tabs } from '@prosazhin/pbcomponents';

<Tabs
  defaultIndex={0}
  theme='pill'
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((label) => (
    <Tab
      key={label}
      label={label}
    >
      <div style={{ marginTop: 24 }}>{`Content for "${label}" tab`}</div>
    </Tab>
  ))}
</Tabs>;
```
