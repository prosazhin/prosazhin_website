`total` — количество страниц. Без внешнего управления задайте `defaultPage`, для управляемого режима — `page` и `onChange`. `siblings` определяет, сколько соседних страниц видно вокруг текущей; остальные сворачиваются в многоточие. Для кнопок «назад» и «вперёд» задайте `prevAriaLabel` и `nextAriaLabel` на языке интерфейса.

## Использование

```tsx
'use client';

import { Pagination } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [page, setPage] = useState(1);
  return (
    <Pagination
      total={20}
      page={page}
      onChange={setPage}
    />
  );
}
```
