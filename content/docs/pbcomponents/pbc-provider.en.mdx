Place it once above components that show dialogs and notifications. Pass settings through `dialog` and `notifications`.

## Usage

```tsx
import { Button, PBCProvider } from '@prosazhin/pbcomponents';

function App() {
  return (
    <PBCProvider notifications={{ top: 20 }}>
      <Button>Ready</Button>
    </PBCProvider>
  );
}
```
