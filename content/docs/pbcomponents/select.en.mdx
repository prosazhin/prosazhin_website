`options` contains `{ display, value, disabled, badge }` objects. `multiple` enables multi-select; `search` enables filtering.

## Usage

```tsx
import { Select } from '@prosazhin/pbcomponents';

const options = ['One', 'Two', 'Three', 'Four', 'Five'].map((display, index) => ({
  display,
  value: String(index),
}));

<Select
  options={options}
  placeholder='Placeholder'
/>;
```
