Polymorphic `as` changes the HTML tag; `medium` increases font weight. `size` is the font size in pixels: `10`, `12`, `14`, `16` (default), `20`, `24`, or `32`. The former `s`, `m`, and `l` map to `12`, `16`, and `20`.

## Usage

```tsx
import { Text } from '@prosazhin/pbcomponents';

<Text
  as='span'
  size={16}
>
  Label
</Text>;
```
