Pass `Radio` elements as children. `onChange` returns the selected `value`. `label`, `description`, and `errorMessage` add a group heading, a hint, and error text. Items keep their own `disabled`, `size`, and `name`.

  name='RadioGroup'
  locale='en'
/>

## Usage

```tsx
import { Radio, RadioGroup } from '@prosazhin/pbcomponents';

<RadioGroup
  label='Options'
  defaultValue='One'
  onChange={(value) => console.log(value)}
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Radio
      key={item}
      value={item}
    >
      {item}
    </Radio>
  ))}
</RadioGroup>;
```
