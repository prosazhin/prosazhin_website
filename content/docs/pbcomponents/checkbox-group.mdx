Дочерние элементы — `Checkbox` или `Toggle`; `onChange` возвращает массив `value`. `label`, `description` и `errorMessage` добавляют заголовок группы, пояснение и текст ошибки. Собственные `disabled`, `size` и `name` пунктов сохраняются.

  locale='ru'
/>

## Использование

```tsx
import { Checkbox, CheckboxGroup } from '@prosazhin/pbcomponents';

<CheckboxGroup
  label='Options'
  defaultValue={['One']}
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Checkbox
      key={item}
      value={item}
    >
      {item}
    </Checkbox>
  ))}
</CheckboxGroup>;
```
