Дочерние элементы — `Checkbox` или `Switch`; `onChange` возвращает массив `value`.

## Живой пример

<ComponentShowcase
  name='CheckboxGroup'
  locale='ru'
/>

## Использование

```tsx
import { Checkbox, CheckboxGroup } from '@prosazhin/pbcomponents';

<CheckboxGroup defaultValue={['One']}>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Checkbox
      key={item}
      value={item}
    >
      {item}
    </Checkbox>
  ))}
</CheckboxGroup>;
```
