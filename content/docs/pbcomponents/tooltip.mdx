Оберните в `Tooltip` один элемент-триггер — он должен принимать `ref` и обработчики событий (`Button`, ссылка, SVG-элемент). Подсказка появляется при наведении с задержкой `delay` и сразу при фокусе с клавиатуры. `placement` задаёт сторону (`top` по умолчанию), при нехватке места подсказка переворачивается. `arrow` показывает стрелку. `maxWidth` ограничивает ширину подсказки (320px по умолчанию, число — пиксели, строка — любое CSS-значение). Внутри `<svg>` или контейнера с `overflow: hidden` включите `portal`. Подсказка не заменяет доступное имя: у кнопки только с иконкой оставьте `aria-label`.

## Использование

```tsx
import { ArrowUpIcon } from '@heroicons/react/24/outline';
import { Button, Tooltip } from '@prosazhin/pbcomponents';

<Tooltip
  content='Back to top'
  placement='left'
>
  <Button
    theme='ghost'
    leftIcon={ArrowUpIcon}
    aria-label='Back to top'
  />
</Tooltip>;
```
