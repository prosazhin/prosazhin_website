Передайте SVG-компонент в `tag`, например иконку Heroicons. `size` — размер в пикселях: `12`, `14`, `16`, `18` (по умолчанию), `20`, `22`, `24`, `26` или `32`. Прежние `s`, `m` и `l` соответствуют `16`, `20` и `24`.

## Живой пример

<ComponentShowcase
  name='Icon'
  locale='ru'
/>

## Использование

```tsx
import { CheckIcon } from '@heroicons/react/24/outline';
import { Icon } from '@prosazhin/pbcomponents';

<Icon
  tag={CheckIcon}
  size={20}
/>;
```
