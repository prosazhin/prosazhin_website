`value` — заполненность от 0 до 100, значения за пределами обрезаются. `size` задаёт толщину полосы, `background: false` скрывает дорожку. Цвет заполненной части меняется через `barClassName`.

## Использование

```tsx
import { Progress } from '@prosazhin/pbcomponents';

<Progress
  value={40}
  size='s'
/>;
```
