The same component as `Popover.Item`. Pass `href` for navigation; use `borderTop` and `borderBottom` for separators and `badge` for a badge. Inside a `Popover`, the popup closes after a click.

## Usage

```tsx
import { PopoverItem } from '@prosazhin/pbcomponents';

<PopoverItem href='/projects'>Projects</PopoverItem>;
```
