`Input.Control` получает строковое `value` и `onChange(value, event)`; дополнения ставятся через `Input.LeftAddon` и `Input.RightAddon`.

## Живой пример

  name='Input'
  locale='ru'
/>

## Использование

```tsx
'use client';

import { Input } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [value, setValue] = useState('');
  return (
    <Input>
      <Input.Control
        value={value}
        onChange={setValue}
        placeholder='Placeholder'
      />
    </Input>
  );
}
```
