`onChange` получает новое состояние, `value` и событие. Используйте для настройки, которая действует сразу.

/>

## Использование

```tsx
'use client';

import { Switch } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [checked, setChecked] = useState(false);
  return (
    <Switch
      value='one'
      checked={checked}
      onChange={setChecked}
    >
      Label
    </Switch>
  );
}
```
