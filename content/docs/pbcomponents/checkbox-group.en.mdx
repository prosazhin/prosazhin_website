Children are `Checkbox` or `Switch`; `onChange` returns an array of values.

<ComponentShowcase
  name='CheckboxGroup'

/>

## Usage

```tsx
import { Checkbox, CheckboxGroup } from '@prosazhin/pbcomponents';

<CheckboxGroup defaultValue={['One']}>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Checkbox
      key={item}
      value={item}
    >
      {item}
    </Checkbox>
  ))}
</CheckboxGroup>;
```
