Children are `Checkbox` or `Toggle`; `onChange` returns an array of values. `label`, `description`, and `errorMessage` add a group heading, a hint, and error text. Items keep their own `disabled`, `size`, and `name`.

/>

## Usage

```tsx
import { Checkbox, CheckboxGroup } from '@prosazhin/pbcomponents';

<CheckboxGroup
  label='Options'
  defaultValue={['One']}
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Checkbox
      key={item}
      value={item}
    >
      {item}
    </Checkbox>
  ))}
</CheckboxGroup>;
```
