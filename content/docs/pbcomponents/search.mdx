Похоже на `Select`, но ввод поиска является основным сценарием. Поддерживает одиночный и множественный выбор.

## Живой пример

<ComponentShowcase
  name='Search'
  locale='ru'
/>

## Использование

```tsx
import { Search } from '@prosazhin/pbcomponents';

const options = ['One', 'Two', 'Three', 'Four', 'Five'].map((display, index) => ({
  display,
  value: String(index),
}));

<Search
  options={options}
  placeholder='Placeholder'
/>;
```
