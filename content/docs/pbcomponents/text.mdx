Полиморфный `as` меняет HTML-тег; `medium` усиливает начертание. `size` — размер шрифта в пикселях: `10`, `12`, `14`, `16` (по умолчанию), `20`, `24` или `32`. Прежние `s`, `m` и `l` соответствуют `12`, `16` и `20`.

## Использование

```tsx
import { Text } from '@prosazhin/pbcomponents';

<Text
  as='span'
  size={16}
>
  Label
</Text>;
```
