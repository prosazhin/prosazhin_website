A unique `id` is required. Use `Dialog.Trigger`, `Content`, `Header`, `Body`, `Footer`, and `Close`.

## Usage

```tsx
import { Dialog } from '@prosazhin/pbcomponents';

<Dialog id='example'>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>Title</Dialog.Header>
    <Dialog.Body>Content</Dialog.Body>
    <Dialog.Footer>
      <Dialog.Close>Close</Dialog.Close>
    </Dialog.Footer>
  </Dialog.Content>
</Dialog>;
```
