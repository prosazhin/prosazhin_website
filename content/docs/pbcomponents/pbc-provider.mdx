Разместите один раз над компонентами, которые вызывают диалоги и уведомления. Настройки передаются через `dialog` и `notifications`.

## Живой пример

<ComponentShowcase
  name='PBCProvider'
  locale='ru'
/>

## Использование

```tsx
import { Button, PBCProvider } from '@prosazhin/pbcomponents';

function App() {
  return (
    <PBCProvider notifications={{ top: 20 }}>
      <Button>Ready</Button>
    </PBCProvider>
  );
}
```
