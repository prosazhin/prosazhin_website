Читает уведомления и предоставляет методы показа и скрытия.
Вызывайте внутри `NotificationsProvider` или `PBCProvider`.

## Использование

```tsx
'use client';

import { useNotifications } from '@prosazhin/pbcomponents';

function Example() {
  const { showNotification } = useNotifications();
  return <button onClick={() => showNotification({ headline: 'Saved' })}>Show</button>;
}
```
