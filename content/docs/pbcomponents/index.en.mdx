`@prosazhin/pbcomponents` is a React 19 component library. The reference covers components, helpers, providers, and hooks with examples and API signatures.

Resources: [GitHub](https://github.com/prosazhin/pbcomponents) · [npm](https://www.npmjs.com/package/@prosazhin/pbcomponents) · [Figma Community](https://www.figma.com/community/file/1214486013859546496) · [Behance](https://www.behance.net/gallery/206064847/pbcomponents).

## Installation

```bash
npm install @prosazhin/pbcomponents @prosazhin/pbstyles
```

The component package has React 19 as a peer dependency and uses Tailwind CSS 4. Import `pbstyles` in your global CSS for its design tokens:

```css
@import 'tailwindcss';
@import '@prosazhin/pbstyles/styles/tailwind/theme.css';
```

## Your first button

```tsx
import { Button } from '@prosazhin/pbcomponents';

export default function Example() {
  return (
    <Button
      size='m'
      color='primary'
      theme='filled'
    >
      Save
    </Button>
  );
}
```

## Dialogs and notifications

If you use `Dialog`, `Notification`, or their hooks, wrap the app in `PBCProvider` once:

```tsx
import { PBCProvider } from '@prosazhin/pbcomponents';

export default function Layout({ children }: { children: React.ReactNode }) {
  return <PBCProvider notifications={{ top: 80 }}>{children}</PBCProvider>;
}
```

This site places the provider in its root layout. Other components do not require a provider.

## Themes and Next.js links

Component colors come from `pbstyles`. Without setup, they follow `prefers-color-scheme`; set `data-theme="dark"` or `data-theme="light"` on `<html>` or a container to override it.

Components with `href` (`Button`, `Tab`, `DropdownItem`, `Tag`) accept `linkComponent` when you need `next/link` instead of a plain anchor:

```tsx
import NextLink from 'next/link';
import { Button } from '@prosazhin/pbcomponents';

<Button
  href='/projects'
  linkComponent={NextLink}
>
  Projects
</Button>;
```
