`summary` is required and accepts markup — for example, text with a `Badge`. Set `defaultOpen` initially, or `open` with `onOpenChange` for a controlled disclosure.

## Usage

```tsx
import { Collapse } from '@prosazhin/pbcomponents';

<Collapse summary='Summary'>Collapse item content</Collapse>;
```
