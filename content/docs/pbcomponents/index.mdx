`@prosazhin/pbcomponents` — библиотека компонентов для React 19. Справочник охватывает компоненты, хелперы, провайдеры и хуки с примерами и сигнатурами API.

Ресурсы: [GitHub](https://github.com/prosazhin/pbcomponents) · [npm](https://www.npmjs.com/package/@prosazhin/pbcomponents) · [Figma Community](https://www.figma.com/community/file/1214486013859546496) · [Behance](https://www.behance.net/gallery/206064847/pbcomponents).

## Установка

```bash
npm install @prosazhin/pbcomponents @prosazhin/pbstyles
```

Пакет компонентов использует React 19 как peer dependency и Tailwind CSS 4. Для фирменных токенов подключите `pbstyles` в глобальном CSS:

```css
@import 'tailwindcss';
@import '@prosazhin/pbstyles/styles/tailwind/theme.css';
```

## Первая кнопка

```tsx
import { Button } from '@prosazhin/pbcomponents';

export default function Example() {
  return (
    <Button
      size='m'
      color='primary'
      theme='filled'
    >
      Сохранить
    </Button>
  );
}
```

## Диалоги и уведомления

Если используете `Dialog`, `Notification` или связанные хуки, оберните приложение в `PBCProvider` один раз:

```tsx
import { PBCProvider } from '@prosazhin/pbcomponents';

export default function Layout({ children }: { children: React.ReactNode }) {
  return <PBCProvider notifications={{ top: 80 }}>{children}</PBCProvider>;
}
```

На этом сайте провайдер расположен в корневом layout. Для остальных компонентов дополнительный провайдер не нужен.

## Тема и ссылки Next.js

Цвета компонентов берутся из `pbstyles`. Без настройки они следуют `prefers-color-scheme`; `data-theme="dark"` или `data-theme="light"` на `<html>` либо контейнере задаёт режим вручную.

Компоненты с `href` (`Button`, `Tab`, `DropdownItem`, `Tag`) принимают `linkComponent`, если вместо обычной ссылки нужен `next/link`:

```tsx
import NextLink from 'next/link';
import { Button } from '@prosazhin/pbcomponents';

<Button
  href='/projects'
  linkComponent={NextLink}
>
  Проекты
</Button>;
```
