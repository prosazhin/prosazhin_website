State that can be controlled by a value prop or stored inside the component.

## Usage

```tsx
'use client';

import { useControllableState } from '@prosazhin/pbcomponents';

function Example() {
  const [open, setOpen] = useControllableState({ defaultValue: false });
  return <button onClick={() => setOpen(!open)}>{open ? 'Open' : 'Closed'}</button>;
}
```
