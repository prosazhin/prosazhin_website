Сочетает текст, размер и иконки. `as` позволяет выбрать подходящий HTML-тег. `size` — размер текста в пикселях (`10`–`32`, по умолчанию `16`); иконки и отступ между ними подбираются под него, как в `.content` из Figma. Прежние `s`, `m` и `l` соответствуют `12`, `16` и `20`.

## Использование

```tsx
import { CheckIcon } from '@heroicons/react/24/outline';
import { Content } from '@prosazhin/pbcomponents';

<Content
  leftIcon={CheckIcon}
  size={16}
>
  Done
</Content>;
```
