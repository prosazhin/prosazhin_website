Compose `Field.Label`, `Field.Control`, `Field.Description`, and `Field.Error`. `error` marks invalid input. `Field.Description` and `Field.Error` texts are linked to the control via `aria-describedby`; the control's own `error` is kept.

## Usage

```tsx
'use client';

import { Field, Input } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [value, setValue] = useState('');
  return (
    <Field error={!value}>
      <Field.Label>Label</Field.Label>
      <Field.Control>
        <Input>
          <Input.Control
            value={value}
            onChange={setValue}
            placeholder='Placeholder'
          />
        </Input>
      </Field.Control>
      <Field.Description>Description</Field.Description>
      {!value && <Field.Error>Fill in the field</Field.Error>}
    </Field>
  );
}
```
