Нужен уникальный `id`. Доступны `Dialog.Trigger`, `Content`, `Header`, `Body`, `Footer`, `Close`. На мобильных диалог открывается шторкой снизу, её можно смахнуть вниз. Затемнение тёмное в обеих темах. Для подтверждения действия есть готовый [ConfirmDialog](/docs/pbcomponents/confirm-dialog).

## Использование

```tsx
import { Dialog } from '@prosazhin/pbcomponents';

<Dialog id='example'>
  <Dialog.Trigger>Open</Dialog.Trigger>
  <Dialog.Content>
    <Dialog.Header>Title</Dialog.Header>
    <Dialog.Body>Content</Dialog.Body>
    <Dialog.Footer>
      <Dialog.Close>Close</Dialog.Close>
    </Dialog.Footer>
  </Dialog.Content>
</Dialog>;
```
