Передайте дочерними элементами `Button` и `Popover` с кнопкой в `Popover.Trigger`. Общий размер задавайте на группе — он применяется ко всем кнопкам, включая триггер меню.

## Живой пример

<ComponentShowcase
  name='ButtonGroup'
  locale='ru'
/>

## Использование

```tsx
import { Button, ButtonGroup, Popover } from '@prosazhin/pbcomponents';

<ButtonGroup size='m'>
  <Button theme='border'>One</Button>
  <Button theme='border'>Two</Button>
  <Popover>
    <Popover.Trigger>
      <Button theme='border'>Three</Button>
    </Popover.Trigger>
    <Popover.Content>
      <Popover.Item>One</Popover.Item>
      <Popover.Item>Two</Popover.Item>
      <Popover.Item>Three</Popover.Item>
    </Popover.Content>
  </Popover>
</ButtonGroup>;
```
