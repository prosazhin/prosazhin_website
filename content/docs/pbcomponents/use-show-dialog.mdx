Регистрирует диалог и возвращает функцию его открытия.
Вызывайте внутри `DialogProvider` или `PBCProvider`.

## Использование

```tsx
'use client';

import { Dialog, useShowDialog } from '@prosazhin/pbcomponents';

function Example() {
  const open = useShowDialog(() => (
    <Dialog id='example'>
      <Dialog.Content>
        <Dialog.Body>Content</Dialog.Body>
      </Dialog.Content>
    </Dialog>
  ));
  return <button onClick={open}>Open</button>;
}
```
