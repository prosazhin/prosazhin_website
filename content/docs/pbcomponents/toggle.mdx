`onChange` получает новое состояние, `value` и событие. Используйте для настройки, которая действует сразу. `description` добавляет текст под подписью.

## Использование

```tsx
'use client';

import { Toggle } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [checked, setChecked] = useState(false);
  return (
    <Toggle
      value='one'
      checked={checked}
      onChange={setChecked}
    >
      Label
    </Toggle>
  );
}
```
