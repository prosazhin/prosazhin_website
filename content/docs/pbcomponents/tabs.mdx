Передайте массив `Tab` как дочерние элементы. `theme` задаёт оформление: `line` (по умолчанию), `pill` или `pill-secondary`. `index` включает управляемый режим, `defaultIndex` — начальную вкладку. `onChange` получает индекс и событие; вызывается и при переключении с клавиатуры — стрелками, `Home` и `End`. Разметка использует роли `tablist`, `tab` и `tabpanel`.

## Использование

```tsx
import { Tab, Tabs } from '@prosazhin/pbcomponents';

<Tabs
  defaultIndex={0}
  theme='pill'
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((label) => (
    <Tab
      key={label}
      label={label}
    >
      <div style={{ marginTop: 24 }}>{`Content for "${label}" tab`}</div>
    </Tab>
  ))}
</Tabs>;
```
