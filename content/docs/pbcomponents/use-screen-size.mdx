Возвращает ширину и высоту окна, обновляясь при resize.
При серверном рендеринге начальные значения — `0 × 0`; после монтирования хук читает размер окна.

## Использование

```tsx
'use client';

import { useScreenSize } from '@prosazhin/pbcomponents';

function Example() {
  const { width, height } = useScreenSize();
  return (
    <span>
      {width} × {height}
    </span>
  );
}
```
