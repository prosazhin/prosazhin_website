Pass an SVG component to `tag`, for example a Heroicons icon. `size` is the size in pixels: `12`, `14`, `16`, `18` (default), `20`, `22`, `24`, `26`, or `32`. The former `s`, `m`, and `l` map to `16`, `20`, and `24`.

<ComponentShowcase
  name='Icon'

/>

## Usage

```tsx
import { CheckIcon } from '@heroicons/react/24/outline';
import { Icon } from '@prosazhin/pbcomponents';

<Icon
  tag={CheckIcon}
  size={20}
/>;
```
