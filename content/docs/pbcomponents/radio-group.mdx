Передайте `Radio` дочерними элементами. `onChange` возвращает `checked`, `value` и событие.

## Живой пример

<ComponentShowcase
  name='RadioGroup'
  locale='ru'
/>

## Использование

```tsx
import { Radio, RadioGroup } from '@prosazhin/pbcomponents';

<RadioGroup defaultValue='One'>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Radio
      key={item}
      value={item}
    >
      {item}
    </Radio>
  ))}
</RadioGroup>;
```
