Передайте `Radio` дочерними элементами. `onChange` возвращает выбранное `value`. `label`, `description` и `errorMessage` добавляют заголовок группы, пояснение и текст ошибки. Собственные `disabled`, `size` и `name` пунктов сохраняются.

/>

## Использование

```tsx
import { Radio, RadioGroup } from '@prosazhin/pbcomponents';

<RadioGroup
  label='Options'
  defaultValue='One'
  onChange={(value) => console.log(value)}
>
  {['One', 'Two', 'Three', 'Four', 'Five'].map((item) => (
    <Radio
      key={item}
      value={item}
    >
      {item}
    </Radio>
  ))}
</RadioGroup>;
```
