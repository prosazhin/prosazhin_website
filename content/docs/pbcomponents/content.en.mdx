Combines text, size, and icons. `as` lets you choose the appropriate HTML tag. `size` is the text size in pixels (`10`–`32`, default `16`); icons and the gap follow it, like `.content` in Figma. The former `s`, `m`, and `l` map to `12`, `16`, and `20`.

  locale='en'
/>

## Usage

```tsx
import { CheckIcon } from '@heroicons/react/24/outline';
import { Content } from '@prosazhin/pbcomponents';

<Content
  leftIcon={CheckIcon}
  size={16}
>
  Done
</Content>;
```
