`Input.Control` receives a string `value` and `onChange(value, event)`; use `Input.LeftAddon` and `Input.RightAddon` for addons.

## Usage

```tsx
'use client';

import { Input } from '@prosazhin/pbcomponents';
import { useState } from 'react';

function Example() {
  const [value, setValue] = useState('');
  return (
    <Input>
      <Input.Control
        value={value}
        onChange={setValue}
        placeholder='Placeholder'
      />
    </Input>
  );
}
```
