Pass `Button` elements and `Popover` with a `Button` in `Popover.Trigger` as children. Set the shared size on the group — it applies to every button, including the menu trigger.

<ComponentShowcase
  name='ButtonGroup'

/>

## Usage

```tsx
import { Button, ButtonGroup, Popover } from '@prosazhin/pbcomponents';

<ButtonGroup size='m'>
  <Button theme='border'>One</Button>
  <Button theme='border'>Two</Button>
  <Popover>
    <Popover.Trigger>
      <Button theme='border'>Three</Button>
    </Popover.Trigger>
    <Popover.Content>
      <Popover.Item>One</Popover.Item>
      <Popover.Item>Two</Popover.Item>
      <Popover.Item>Three</Popover.Item>
    </Popover.Content>
  </Popover>
</ButtonGroup>;
```
