`value` is the fill from 0 to 100; values outside are clamped. `size` sets the bar thickness, and `background: false` hides the track. Change the fill color with `barClassName`.

<ComponentShowcase

## Usage

```tsx
import { Progress } from '@prosazhin/pbcomponents';

<Progress
  value={40}
  size='s'
/>;
```
