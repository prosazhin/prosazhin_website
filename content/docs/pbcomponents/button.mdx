Для действия используйте `onClick`, для перехода — `href`. `loading` показывает выполнение операции; `disabled` блокирует действие — у задизейбленной ссылки `onClick` тоже не вызывается. Кнопка только с иконкой квадратная; для неё задайте `aria-label` или оберните в [Tooltip](/docs/pbcomponents/tooltip).

## Использование

```tsx
import { Button } from '@prosazhin/pbcomponents';

<Button
  size='m'
  theme='filled'
  color='primary'
>
  Button
</Button>;
```
