title: Button

---

import ComponentShowcase from '@/components/docs/ComponentShowcase';
import ComponentAPI from '@/components/docs/ComponentAPI';

Use `onClick` for an action and `href` for navigation. `loading` shows progress; `disabled` blocks interaction — a disabled link does not call `onClick` either. An icon-only button is square; give it an `aria-label` or wrap it in a [Tooltip](/docs/pbcomponents/tooltip).

## Usage

```tsx
import { Button } from '@prosazhin/pbcomponents';

<Button
  size='m'
  theme='filled'
  color='primary'
>
  Button
</Button>;
```
